
# 【南特金属】退货政策文档 V2.0

## 第一章 总则

### 第一条 政策目的
为保障消费者合法权益，明确买卖双方在退货过程中的权利与义务，依据《中华人民共和国消费者权益保护法》《网络交易管理办法》及相关法律法规，结合汽车零配件行业特点，制定本退货政策。

### 第二条 基本原则
诚信原则：买家应如实反映商品状况，不得恶意退货；卖家应诚实守信，不得设置不合理退货门槛。
公平原则：退货责任划分以事实为依据，不以买家评价等级、购买金额等因素区别对待。
效率原则：退货申请应在承诺时限内处理完毕，不得无故拖延。

### 第三条 定义
退货：买家将已购商品退回给卖家，卖家退还相应款项的行为。
换货：买家将已购商品退回给卖家，卖家重新发送同款或约定替代商品的行为。
七天无理由退货：买家在签收商品之日起七日内，无需说明理由即可发起退货。
质量问题退货：因商品存在材料、工艺、功能等方面的缺陷而发起的退货。
签收日：物流信息显示"已签收"的日期。如买家实际未收到但物流显示签收，以买家实际取件日为准。

## 第二章 七天无理由退货

### 第四条 适用条件
买家自签收商品之日起七日内，满足以下全部条件的，可申请无理由退货——
商品未安装、未使用、未上车测试；
商品外观、结构、功能完好无损，无划痕、磕碰、变形、油液泄漏等痕迹；
商品原包装完整，包括但不限于：包装盒/箱、内衬泡沫、塑料袋、标签吊牌、说明书、保修卡、合格证、赠品等；
商品未被拆封（一次性密封包装已破坏的，视为影响二次销售）；
非油液类商品（机油、刹车油、防冻液、冷媒等）未开封；
非定制/定做/特殊订货商品；
非贴身类商品（如座椅套、方向盘套等，已拆封影响卫生的）。

### 第五条 不适用七天无理由退货的情形
以下情形不适用七天无理由退货——

| 序号 | 情形 | 原因说明 |
| 1 | 油液类商品已开封 | 无法确认是否被掺假或污染 |
| 2 | 密封包装已拆封的电子电器件 | 如传感器、执行器、ECU等，通电后可能留下使用痕迹或数据 |
| 3 | 已安装或使用过的商品 | 无法恢复至全新状态二次销售 |
| 4 | 定制/定做商品 | 如按客户要求改制的线束、支架等，无法转售他人 |
| 5 | 特别订货商品 | 从海外或厂家单独订购的非库存商品 |
| 6 | 超过七天期限 | 超出法定无理由退货窗口 |
| 7 | 商品有明显人为损坏 | 如摔裂、进水、烧毁等 |
| 8 | 赠品已使用或丢失 | 导致整套商品无法按原样退回 |


### 第六条 七天无理由退货的费用承担

| 费用项目 | 承担方 | 说明 |
| 退回运费 | 买家 | 按实际发生的快递费用计算 |
| 原订单运费 | 买家 | 原订单包邮的，扣除发货时实际运费后退款 |
| 包装材料费 | 卖家 | 不收取 |
| 上门取件服务费 | 买家 | 如选择平台上门取件，费用由买家承担 |

示例说明：
买家A购买商品¥200，订单包邮，实际发货运费¥15。
A申请七天无理由退货，寄回运费¥18。
退款金额 = ¥200 - ¥15（原发货运费）= ¥185。
A实际支出 = ¥15（原运费）+ ¥18（退回运费）= ¥33。

## 第三章 质量问题退货

### 第七条 质量问题的认定标准
以下情形认定为质量问题——

| 类别 | 具体表现 |
| 功能失效 | 商品无法实现其基本功能，如发电机不发电、水泵不泵水、传感器无信号输出 |
| 性能不达标 | 商品功能正常但性能明显低于标称值，如刹车片摩擦系数不足、LED灯泡亮度远低于宣称流明值 |
| 材质缺陷 | 存在铸造砂眼、裂纹、气泡、脱层、锈蚀等材料缺陷 |
| 尺寸不符 | 关键安装尺寸与标称规格偏差超过允许公差，导致无法正常安装 |
| 外观严重瑕疵 | 大面积划伤、磕碰凹陷、油漆剥落、变形等影响正常使用或美观的缺陷 |
| 配件缺失 | 包装清单所列附件缺失，且影响正常安装或使用 |
| 标识错误 | 商品标签标注的型号、规格与实际商品不符 |


### 第八条 不认定为质量问题的情形
以下情形不属于质量问题——

| 序号 | 情形 | 说明 |
| 1 | 买家买错型号/规格 | 购买前未核实适配性，商品本身无缺陷 |
| 2 | 正常使用磨损 | 如刹车片磨薄、雨刮胶条老化、灯泡自然衰减 |
| 3 | 安装不当导致的损坏 | 如螺栓扭矩过大导致滑丝、线路接反导致烧毁 |
| 4 | 车辆自身故障导致新件损坏 | 如发电机故障导致新电瓶亏电报废 |
| 5 | 事故、碰撞、进水等人为因素 | 如涉水行驶导致传感器进水损坏 |
| 6 | 改装或超负荷使用 | 如更换大功率灯泡导致灯座熔化 |
| 7 | 主观感受差异 | 如觉得刹车偏软（实际在正常范围内）、觉得噪音略大（实际符合行业标准） |
| 8 | 轻微外观差异 | 如包装盒挤压但不影响内部商品、表面微小划痕（长度＜1cm且不影响功能） |


### 第九条 质量问题退货的处理方式

| 处理方式 | 适用情形 | 具体操作 |
| 全额退款 | 功能性故障、材质缺陷、严重外观瑕疵 | 买家退回商品 → 卖家收到后24小时内全额退款（含运费） |
| 换新 | 功能性故障，买家仍需要该商品 | 买家退回故障品 → 卖家收到后48小时内发出新品 |
| 先发后退 | 买家急需使用，且商品价值≤¥500 | 卖家先发出新品 → 买家收到后将故障品寄回（限7天内） |
| 部分退款 | 轻微瑕疵不影响使用，买家愿意接受 | 双方协商补偿金额（通常为售价的10%-30%） |
| 上门取件 | 大件商品（减震器、方向机、冷凝器等） | 卖家安排快递上门取件，买家无需自行寄回 |


### 第十条 质量问题退货的费用承担

| 费用项目 | 承担方 | 说明 |
| 退回运费 | 卖家 | 按实际发生金额全额承担 |
| 原订单运费 | 卖家 | 全额退还 |
| 上门取件费 | 卖家 | 如选择上门取件，费用由卖家承担 |
| 安装工时费 | 协商 | 如因质量问题导致已产生的安装费，凭票据协商补偿（通常不超过¥100） |
| 检测费 | 卖家 | 如需第三方检测，费用由卖家预付 |


## 第四章 换货政策

### 第十一条 换货适用情形

| 情形 | 说明 | 是否可换货 |
| 质量问题 | 商品存在功能或材质缺陷 | ✅ 可以 |
| 发错货 | 收到的商品与订单不一致 | ✅ 可以 |
| 尺码/规格不合适 | 买家买错型号（未安装） | ✅ 可以（按无理由退货处理） |
| 颜色/款式不喜欢 | 主观偏好问题（未安装） | ✅ 可以（按无理由退货处理） |
| 已安装后发现不合适 | 商品本身无问题 | ❌ 不可以 |


### 第十二条 换货流程
流程一：买家申请换货 -> 客服审核（≤2小时）-> 审核通过 -> 生成换货单号

流程二：买家申请换货 -> 客服审核（≤2小时）-> 审核通过 -> 买家寄回原商品（7天内寄出） -> 卖家签收并验货（1-3个工作日） -> 验货通过 -> 发出换货商品（48小时内）

流程三：买家申请换货 -> 客服审核（≤2小时）-> 审核通过 -> 买家寄回原商品（7天内寄出） -> 卖家签收并验货（1-3个工作日） -> 验货通过 -> 买家收到换货商品

### 第十三条 换货运费规则

| 换货原因 | 寄回运费 | 再次发货运费 |
| 质量问题 | 卖家承担 | 卖家承担 |
| 发错货 | 卖家承担 | 卖家承担 |
| 买家买错/不喜欢 | 买家承担 | 买家承担 |
| 换货后仍有问题 | 卖家承担 | 卖家承担 |


## 第五章 退货申请与处理流程

### 第十四条 退货申请渠道
买家可通过以下任一渠道提交退货申请——
店铺在线客服：直接联系客服，提供订单号和退货原因。
平台售后入口：在订单详情页点击"申请售后"。
客服微信：添加客服微信号 nante_parts，发送退货请求。
客服电话：拨打 400-888-8888，由客服代为提交。

### 第十五条 退货申请所需信息
买家提交退货申请时，应提供以下信息——

| 信息项 | 是否必填 | 说明 |
| 订单编号 | 是 | 可在订单详情页查找 |
| 退货原因 | 是 | 选择或填写具体原因 |
| 商品状态描述 | 是 | 是否安装、是否使用、外观状况等 |
| 照片/视频证据 | 质量问题必填 | 清晰展示故障部位或缺陷 |
| 期望处理方式 | 否 | 退款/换货/部分补偿，如未填写默认退款 |
| 联系电话 | 是 | 便于快递联系 |
| 退货地址 | 否 | 如与收货地址不同，请提供 |


### 第十六条 退货审核时效

| 申请类型 | 审核时效 | 说明 |
| 七天无理由退货 | ≤2小时 | 系统自动审核或人工快速审核 |
| 质量问题退货 | ≤24小时 | 需人工核实证据 |
| 换货申请 | ≤24小时 | 需确认库存情况 |
| 争议性退货 | ≤48小时 | 需双方沟通或平台介入 |


### 第十七条 退货寄回要求
寄回时限：审核通过后，买家须在7天内将商品寄出，逾期未寄出的，退货申请自动关闭。
包装要求：
使用原包装寄回，如原包装已丢弃，请使用同等强度的包装箱。
易碎品（灯具、传感器、电器件等）必须填充足够的缓冲材料（泡沫、气泡膜、报纸等）。
油液类商品必须密封严实，外层加套防水袋。
快递选择：
建议使用顺丰、京东、中通、圆通等可追踪物流的快递。
价值超过¥500的商品，建议保价运输（保价费由寄件方承担）。
不接受平邮、到付（质量问题除外）。
随货单据：包裹内请放置一张纸条，写明订单号、买家姓名、联系电话、退货原因，以便仓库快速识别处理。

### 第十八条 仓库验收标准

| 验收结果 | 处理方式 |
| 商品完好，符合退货条件 | 通过验收，进入退款/换货流程 |
| 商品有使用痕迹 | 拒绝退货，原路退回，运费由买家承担 |
| 商品有人为损坏 | 拒绝退货，原路退回，运费由买家承担 |
| 配件/附件缺失 | 按缺失价值扣除部分退款，或拒绝退货 |
| 包装严重破损 | 酌情扣减退款金额（通常为售价的5%-10%） |
| 寄回商品与订单不符 | 联系买家确认，如无法确认则原路退回 |


### 第十九条 退款时效

| 退款类型 | 退款时效 | 说明 |
| 无理由退货退款 | 仓库验收通过后 ≤24小时 | 按实际到账时间 |
| 质量问题退款 | 仓库验收通过后 ≤24小时 | 含运费全额退还 |
| 仅退款（未退货） | 审核通过后 ≤48小时 | 适用于部分退款或小额补偿 |
| 换货补差价退款 | 换货发出后 ≤24小时 | 如有差价需退还 |

退款路径：按原支付方式原路退回。
微信支付：即时到账（部分银行延迟至T+1）
支付宝：即时到账
银行卡：T+1至T+3个工作日

## 第六章 特殊商品退货规定

### 第二十条 大件商品退货
定义：单件重量超过15kg或最长边超过100cm的商品，如减震器、方向机、冷凝器、散热器、保险杠等。
特殊规定：
七天无理由退货同样适用，但退回运费较高（通常为¥30-¥80），请买家知悉。
质量问题退货时，卖家安排快递上门取件，买家无需自行搬运寄送。
建议买家在签收时当场开箱验货，如发现运输损坏，直接拒收并联系客服。

### 第二十一条 油液类商品退货
定义：机油、刹车油、防冻液、助力油、冷媒、化清剂等液体商品。
特殊规定：
未开封：支持七天无理由退货，退回时需确保密封完好，外层加套防水袋。
已开封：不支持任何形式的退货，无论是否使用。原因是无法确认开封后是否被掺假或污染。
泄漏处理：如收到时已泄漏，请拍照留证，联系客服补发或退款，无需退回。

### 第二十二条 电器电子类商品退货
定义：发电机、启动马达、压缩机、传感器、执行器、ECU、控制模块等。
特殊规定：
未通电测试：支持七天无理由退货。
已通电测试：视为已使用，不支持无理由退货。原因是通电后可能留下数据痕迹或静电损伤。
质量问题：即使已安装使用，只要确认是商品本身缺陷，仍支持退货退款。
防水标签：部分电器件贴有防水标签，遇水变色即视为进水损坏，不予保修。

### 第二十三条 定制/定做商品退货
定义：按客户特定要求加工、改制、定制的商品，如定制长度的高压油管、特殊接口的线束、刻字零件等。
特殊规定：
不支持七天无理由退货。
质量问题：如定制商品存在做工缺陷或与约定规格不符，支持退货退款。
买家提供数据错误：如买家提供的尺寸、接口等信息有误导致商品无法使用，不支持退货。建议定制前与客服反复确认数据。

### 第二十四条 促销/特价商品退货
定义：参与满减、折扣、秒杀、清仓等活动的商品。
特殊规定：
退货政策与常规商品完全一致，不因促销而缩减退货权益。
退款金额按实际支付金额计算，而非商品原价。
如退货后导致订单不满足满减条件，满减优惠金额将从退款中扣除。
示例：
订单总价¥500，满减优惠¥50，实际支付¥450。
退回其中一件价值¥200的商品。
退款金额 = ¥200 - （¥200 ÷ ¥500 × ¥50）= ¥200 - ¥20 = ¥180。

## 第七章 争议处理

### 第二十五条 双方争议的解决途径
如买卖双方就退货事宜无法达成一致，可按以下顺序寻求解决——
双方协商：联系店铺客服，说明分歧点，争取友好解决。
平台客服介入：申请平台官方客服介入调解。
平台仲裁：提交证据材料，由平台仲裁委员会作出裁决。
消费者协会投诉：拨打12315或登录全国12315平台投诉。
法律诉讼：向合同履行地人民法院提起诉讼。

### 第二十六条 举证责任分配

| 争议类型 | 举证方 | 举证内容 |
| 是否存在质量问题 | 买家主张质量问题 → 买家举证 | 提供清晰照片、视频、第三方检测报告等 |
| 是否为人为损坏 | 卖家主张人为损坏 → 卖家举证 | 提供开箱视频、检测报告等 |
| 是否已安装使用 | 卖家主张已安装 → 卖家举证 | 提供安装痕迹照片、磨损特征等 |
| 是否在保修期内 | 卖家主张过期 → 卖家举证 | 提供订单时间和保修条款 |
| 是否发错货 | 买家主张发错 → 买家举证 | 提供收到的商品照片和订单截图对比 |


### 第二十七条 第三方检测
如双方对商品质量存在重大分歧，可委托具有资质的第三方检测机构进行鉴定——
检测机构：双方协商选定，如无法协商一致，由平台指定。
检测费用：
检测结果支持买家主张：检测费由卖家承担。
检测结果支持卖家主张：检测费由买家承担。
检测结果部分支持双方：检测费双方分摊。
检测周期：一般为7-15个工作日。
检测结论效力：检测报告为最终依据，双方均应接受。

## 第八章 违规与处罚

### 第二十八条 买家违规行为
以下行为视为买家违规，店铺有权拒绝退货申请并保留追究法律责任的权利——
恶意退货：频繁购买后退货，退货率超过50%（月统计）。
掉包欺诈：退回的商品与发出的商品不一致（如退回旧件冒充新件）。
虚假申报：虚构质量问题，骗取退款或补偿。
恶意差评勒索：以差评为要挟，要求额外补偿或全额退款不退货。
滥用退货政策：如购买多件同款商品，试用后退回部分商品。

### 第二十九条 卖家违规行为
以下行为视为卖家违规，买家可向平台投诉——
无理拒绝退货：符合退货条件却故意刁难、拒绝受理。
拖延退款：验收通过后超过承诺时效未退款。
虚假承诺：承诺的保修政策与实际执行不一致。
打击报复：因买家退货而对买家进行骚扰、辱骂、泄露隐私等。
设置不合理门槛：要求买家提供退货政策之外的额外证明或条件。
